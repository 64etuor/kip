# Historical designs

These dated designs preserve decisions and target tradeoffs. They are not
execution instructions or evidence that a feature is currently ready. Use the
current [PRD](../PRD.md), [TRD](../TRD.md), [ADRs](../adr/), and
[implementation status](../IMPLEMENTATION_STATUS.md) for current work.

Superseded step-by-step implementation checklists were removed. Their code and
tests now live in the repository, their decisions live in the paired designs
or ADRs, and the original checklists remain in
[Git history](https://github.com/64etuor/kip/tree/1b04bad685762fe3002d9c4ec6a75f267df9fb94/docs/plans).
Historical designs and audits are not shipped in either distribution; links
from shipped documents point to pinned historical sources when needed.
